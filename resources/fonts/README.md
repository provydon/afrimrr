# Bundled fonts

`DejaVuSans.ttf` / `DejaVuSans-Bold.ttf` are used by `OgImageController` to
render the dynamic per-startup social unfurl card (GD / FreeType needs a real
TTF on disk — web fonts/woff2 won't do).
